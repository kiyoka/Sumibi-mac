# 診断・デバッグ画面（Issue #62）

Sumibi設定のトップレベルにある「診断・デバッグ…」から開く。
一時デバッグは原文の取得・照合・変換結果の反映を調べるためのものであり、
Decisionsの有効化・同意・キーは画面を開いたり表示を切り替えたりする条件にしない。
ただし、ここで自動変換やAPIへの送信条件を迂回できるわけではない。

従来の一時デバッグ項目をDecisions設定から移動した。Decisions設定にはスコア・閾値・
通信回数・見送り理由など、自動変換固有の設定と状態を残す。
保持するデータや収集する条件は変更せず、診断状態を永続設定へ移す変更もしない。

## 使い方

1. 「原文・取得文字列を設定画面に表示」をオンにする。
2. 診断画面と設定を閉じ、機密情報を含まない短い文で確認する。
3. 不具合が再発したら追加入力せず、同じ診断画面を開く。
4. 見送り時の原文比較、原文確定後の取得文字列、置換後の期待結果と取得文字列を確認する。
5. 調査後はオフにする。

見送り・失敗がまだ起きていないと、表示する比較情報がないことがある。通常のメニューの
エラー通知とは別の表示である。手動変換と自動変換で、現在収集できる情報が同じとは限らない。
画面を開くための停止では失敗時の情報を保持し、入力先の追加読取・書込・通信はしない。

## プライバシー

既定オフ・明示オン時だけ・プロセスのメモリ内限定。再起動後はオフになる。
ログ・UserDefaults・ファイルへ原文や取得文字列を保存しない。オフ・設定変更・次の観測や
適用試行・成功で、対象の表示用文字列を破棄する。取得文字列に別の文章が含まれる可能性が
あるため、機密情報を入力しない。診断をオンにしても原文の安全照合を緩和しない。
