# 回帰テストの実行と実機確認

## 自動テスト

リポジトリのルートで実行する。対応するmacOSとSwift 6.2以降の開発環境が必要。

```sh
swift test
```

Issue #12の作業版はCore 76件とIME側72件（計148件）。通常実行は147件を確認し、実60秒タイムアウトの1件は明示的にスキップする。Issue #46ではIME側の#45の20件に加え、以下の36件を追加した。Coreにも長いAPIキーの伏せ字が固定長になることを確認する1件を追加した。

| 対象 | 件数 | 検証すること |
| --- | --- | --- |
| SettingsStore | 9 | 保存・再読込、破損データ、正規化、旧モデルの一度だけの移行、送信先ごとの同意、旧設定の移行と上書き防止 |
| APIKeyStore | 8 | 読込・更新・追加・削除、失敗の伝播、保存先の固定、端末限定・iCloud同期無効の属性 |
| InputEffectApplierとRuntime | 9 | 原文の確定、UTF-16範囲、古いカーソル位置、選択変換、誤置換の拒否、Escと入力先切替、待機制御キーの非実行 |
| ConversionCoordinator | 4 | APIキー欠落・Keychain失敗・送信同意なしでクライアントを作らない、同意後の設定反映、文字数超過時の通信防止 |
| APISettingsModel | 6 | 保存済みキーの短い表示、変更開始・キャンセル、保存成功・失敗後の編集状態、伏せ字をキーとして保存しないこと |

### 分離の約束

- 設定にはUUID付きの`org.sumibi.tests.*`専用UserDefaultsを使い、テスト終了時にそのドメインだけを削除する。旧設定の移行元も別の専用ドメインへ差し替える。
- Keychainは`RecordingKeychain`に差し替え、Security APIへ問い合わせない。保存・更新・削除で使うクエリーと属性を記録し、ダミーキーだけを使う。
- 変換サービスは固定応答に差し替え、実ネットワークへ送信しない。既存CoreのHTTPテストもURLProtocolによる模擬応答を使う。
- 入力先は`RecordingInputClient`、候補窓は模擬ウィンドウを使う。Runtimeは新規インスタンスとし、`.shared`や実IMK登録は使わない。入力内容の診断フラグも既定のfalseのまま扱う。
- 通常の実行では差し替えを指定せず、従来どおりIMK・標準設定・Security API・OpenAI互換クライアントへ接続する。

## 開発機能の境界（#47）

IME側に6件を追加し、残存する開発設定の無効化、既定値、未知の設定、模擬応答のコンパイル条件、キー・同意の検証を迂回しないこと、登録識別子と実クラスの互換性を検証する。

`SUMIBI_DEVELOPMENT_FEATURES=0 swift test`と`SUMIBI_DEVELOPMENT_FEATURES=1 swift test`を両方実行する。後者では模擬応答の動作も検証し、実通信しない。通常／開発のアプリビルドと成果物検証は[ビルドモード](../docs/BUILD_MODES.md)を参照。実機での入力ソース登録と設定・ユーザー辞書・APIキーの保持は別途本人が確認する。

2026-10-04、#47の通常版へ更新した実機で、利用者が通常変換・候補選択・Escと、設定・ユーザー辞書・保存済みAPIキーの保持に問題がないことを確認した。既存の入力ソース登録を使った更新確認であり、新規登録・別Mac・実公証は確認済みとしない。

## 変換状態・エラー表示（#12）

IME側に状態・固定文・秘密情報の非表示・解除と入力処理の分離・取消の9テストと、明示実行するローカルタイムアウトの1テストを追加した。[表示方針と実測結果](../docs/CONVERSION_FEEDBACK.md)を参照。

```sh
SUMIBI_RUN_TIMEOUT_TEST=1 SUMIBI_DEVELOPMENT_FEATURES=0 swift test --filter ConversionTimeoutIntegrationTests
```

この明示テストだけは127.0.0.1の一時ポートに実URLSessionで接続する。ダミーキー・ダミー入力のみで約60秒かかる。外部APIや本人の設定・Keychainは利用しない。通常の全テストは実ネットワークに依存しない。

2026-10-04、#12の通常版で利用者が変換中のアイコン表示と、エラー発生時の期待動作を実機確認した。エラーの種類・発生方法は報告されておらず、全種類・全環境の確認とは扱わない。

## 配布スクリプトの模擬テスト

```sh
ruby Tests/Distribution/test-distribution.rb /path/to/repository-with-distribution-scripts
```

`Distribution/`が現在のリポジトリにある場合は引数を省略できる。macOS標準のRuby・PlistBuddyとRuby標準ライブラリを使用する。追加のアカウント設定・証明書は不要。

配布スクリプトは#15の別ブランチにあり、この#46の変更へは混ぜていない。#15のコミット`c027ccf`のローカルスナップショットを対象に、以下でも再実行できる。

```sh
set -o pipefail
distribution_snapshot="$(mktemp -d /private/tmp/sumibi-distribution-snapshot.XXXXXX)"
git archive c027ccf Distribution | tar -x -C "$distribution_snapshot"
ruby Tests/Distribution/test-distribution.rb "$distribution_snapshot"
```

2026-10-04、このスナップショットに対する18項目が成功。引数・証明書種別・チーム・Hardened Runtime・タイムスタンプの検証、単一ユーザー用の配置設定、自動再配置の無効化、公証の承認・拒否・送信失敗、staple失敗、Gatekeeper拒否時の停止を検証する。

テストは対象の`Distribution/`を新規一時ディレクトリへコピーし、そのコピーだけを実行する。署名・公証・Gatekeeper・ビルドのツールは専用PATHの模擬ツールへ差し替え、呼び出しと順序を記録する。生成するパッケージとチェックサムはダミーであり配布不可。入力元リポジトリ、実Keychain、インストール済みアプリを変更せず、Appleへ送信しない。テスト作業領域は終了時に削除する。

#15の未マージスクリプトが見つからない場合は明示的に失敗する。検証済み扱いで黙ってスキップしない。実際のDeveloper ID署名・公証・Gatekeeper判定・別Macでの導入は、この模擬テストで確認した扱いにはしない。

## 手動チェックリスト

以下は実際のIMK接続・OSの設定画面・Keychain許可の確認であり、自動テストの成功だけでは検証できない。2026-10-04、#46版の保存済みAPIキー表示と「変更」からの編集操作は、利用者が実機で正しく動作することを確認した。その他の項目は#46版では未実施。#45版での利用者による確認結果は[構成資料](../docs/INPUT_CONTROLLER_ARCHITECTURE.md)に記録している。

- TextEditまたはメモ：通常変換、候補選択、Undoで原文に戻る、Escで下線だけ解除、次のEscがアプリの操作として届く。
- ターミナル.appのzsh：変換キーによる追加候補・巡回、折り返す入力。
- Codex・Chrome系の入力欄：通常変換、選択範囲の変換、候補選択。長文読取制限を回避したとは扱わない。
- 応答待ち中：追加入力、Esc、別アプリ・別入力欄への切替。原文が消えず、古い応答や待機制御キーが新しい入力先へ適用されない。
- 設定画面：送信先・モデル・ユーザー辞書の保存と再起動後の保持、送信先変更後の同意取り直し。
- 実Keychain：本人の操作によるAPIキー保存・読込・削除とOSの許可要求。開発署名からDeveloper ID署名へ移る場合のアクセスは#15で別途確認。
- 配布物：標準ユーザーでの導入、公証チケット、更新時のデータ保持、入力ソース追加は#15で実物を使って確認。

実機用アプリの入れ替えは、利用者がABCなど別の入力ソースへ切り替えてから行う。テストコマンド自体はインストール・起動・入力ソース変更を行わない。
